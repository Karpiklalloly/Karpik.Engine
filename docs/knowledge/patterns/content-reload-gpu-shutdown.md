# Освобождение GPU-ресурсов при остановке Content Reload

Завершение публикации Content подтверждает смену снимка. Старую текстуру могут всё ещё удерживать буфер кадра или список команд. Ожидание освобождения текстуры перед остановкой рендера может зависнуть, если только остановка рендера снимет последнее удержание.

Сначала запросить остановку доставки и прекратить запись кадров. Затем остановить merge worker и освободить удержания из оставшихся кадров и списков команд. После этого дождаться завершения координатора и освобождения реестра Content. Графическое устройство уничтожить последним, чтобы освобождение нативных ресурсов могло пройти через backend.

В Autofac этот порядок обеспечивают зависимости `MergeThread` от `IContentReloadLifetime` и `IContentRegistry`. В ручной композиции порядок нужно обеспечить при остановке. В проверке стоит удерживать старую текстуру в незавершённом кадре во время реальной публикации и запускать остановку с этим удержанием.
