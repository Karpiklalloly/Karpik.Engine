# Раздельный поиск Content по имени и AssetId

Когда legacy-загрузчик должен видеть оригинал, не стройте поиск по имени из уже переопределённых слотов. Храните в одном снимке индекс исходных записей базы по имени и итоговые слоты по `AssetId`. Выбирайте подмены до публикации: чтение по ID остаётся одним lookup без аллокаций.

Если legacy-ресурсы нужны при запуске движка до подготовки ModSet, откройте только индекс по имени. Опубликуйте первый каталог ID уже с подменами и версией 1, чтобы не выдавать временные ссылки на оригинал.

Изменение скрытого оригинала всё равно требует опубликовать новый индекс имён и хранилище базы. Если итоговый слот не изменился, сохраняйте его ссылку и версию и не отправляйте уведомление по ID. В регрессии проверяйте оба пути после одного reload: новые байты по имени, прежние байты, версия и отсутствие события по ID.
