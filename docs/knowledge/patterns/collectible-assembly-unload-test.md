# Проверка выгрузки collectible AssemblyLoadContext

`Unload()` запускает выгрузку. На Windows попытка сразу удалить загруженную DLL может завершиться отказом доступа, пока живы ссылки на её типы или экземпляры.

В тесте вынести загрузку, работу с типами и проверку DI в отдельный метод с `NoInlining`. Освободить контейнер, вызвать `Unload()` в `finally` и вернуть из метода только `WeakReference` на контекст. После выхода из метода дать GC и финализаторам ограниченное число попыток, проверить `IsAlive == false` и затем удалить временные файлы. Так тест проверяет фактическую выгрузку и локализует регрессии, когда контекст удерживает сильная ссылка.
