# Включение и отключение модов

Создайте `mods.json` рядом с каталогом `Mods/` в корне, из которого запущена игра или выделенный сервер. Если клиент и сервер используют разные корни, у каждого свой файл.

```json
{
  "disabled": ["weather-ui", "winter-skins"]
}
```

Используйте `id` из `mod_info.json`, а не имя папки. Регистр важен; повторяющиеся и пока не установленные ID допустимы. Чтобы включить мод, удалите его ID из списка. Без файла или с пустым списком все установленные моды остаются кандидатами на загрузку, как раньше. Повреждённый или нечитаемый `mods.json` останавливает запуск с указанием пути: движок не включает моды в обход ошибки.

Изменения этого файла применяются при **следующем запуске**. Lua reload, Content refresh и явный выбор в открытом мире не перечитывают и не записывают `mods.json`. Выключенные моды не запускают Lua, не поставляют ассеты и не применяют свои подмены. Чужая подмена их ассета пропускается с предупреждением. Если от выключенного мода есть [обязательная зависимость](mod-dependencies.md), запуск отклоняется; необязательная считается отсутствующей.

Если `mod_info.json` синтаксически читается и ID распознан, выключенный мод не проверяется на корректность зависимостей и загружаемых файлов. Синтаксические ошибки manifest обрабатываются как прежде, а дубликаты ID по-прежнему недопустимы, даже у выключенного мода. Эта настройка не удаляет мод и не меняет его файлы.

## Выбор в открытом локальном мире

1. Поместите пакет в `Mods/` и запросите у хоста обновление списка (`DiscoverAsync`). Это не запускает Lua и не применяет ассеты.
2. Передайте хосту полный список выбранных ID (`ApplyAsync`); зависимости не включаются каскадом. Клиент и сервер применяют один выбор без перезапуска мира или переподключения.
3. Если у удаляемой схемы есть живые строки либо остаётся привязка к пулу, запрос отклоняется на обеих сторонах. Разрешённое отключение завершает VM, а повторное включение создаёт новую. Прошлые изменения мира не отменяются. Lua остающихся модов читается из принятого захвата, даже если файлы изменились.

Этот путь доступен только хосту, который владеет обоими worker-процессами и доказал, что их сетевые соединения образуют пару. Сам по себе `localhost` не даёт этого права. [Headless-тест](../../../tests/Karpik.Engine.Core.Runner.Tests/ModLiveTransitionEndToEndTests.cs) показывает вызовы и обработку результата; универсального меню нет. Независимый mod Content refresh сохраняется и работает с принятым набором.
