# Включение и отключение модов

Создайте `mods.json` рядом с каталогом `Mods/` в корне, из которого запущена игра или выделенный сервер. Если клиент и сервер используют разные корни, у каждого свой файл.

```json
{
  "disabled": ["weather-ui", "winter-skins"]
}
```

Используйте `id` из `mod_info.json`, а не имя папки. Регистр важен; повторяющиеся и пока не установленные ID допустимы. Чтобы включить мод, удалите его ID из списка. Без файла или с пустым списком все установленные моды остаются кандидатами на загрузку, как раньше. Повреждённый или нечитаемый `mods.json` останавливает запуск с указанием пути: движок не включает моды в обход ошибки.

Изменения применяются при **следующем запуске**. Перезагрузка Lua, обновление базового Content и обновление модового Content не перечитывают выбор. Выключенные моды не запускают Lua, не поставляют ассеты и не применяют свои подмены. Чужая подмена их ассета пропускается с предупреждением. Если от выключенного мода есть [обязательная зависимость](mod-dependencies.md), запуск отклоняется; необязательная считается отсутствующей.

Если `mod_info.json` синтаксически читается и ID распознан, выключенный мод не проверяется на корректность зависимостей и загружаемых файлов. Синтаксические ошибки manifest обрабатываются как прежде, а дубликаты ID по-прежнему недопустимы, даже у выключенного мода. Эта настройка не удаляет мод и не меняет его файлы.
